# Google Material Symbols

本目录 SVG 原样来自 Google Material Symbols 的 Outlined 系列，24px 规格，供预览离线使用。

页面内联引用相同的 SVG 路径，以支持直接打开本地 HTML；图标颜色通过 `currentColor` 跟随主题。

- 柱状图：`bar_chart.svg`，来源 https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/bar_chart/materialsymbolsoutlined/bar_chart_24px.svg
- 折线图：`show_chart.svg`，来源 https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/show_chart/materialsymbolsoutlined/show_chart_24px.svg
- 曲线图：`multiline_chart.svg`，来源 https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/multiline_chart/materialsymbolsoutlined/multiline_chart_24px.svg

其他图标沿用相同的官方来源路径：
`https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/<名称>/materialsymbolsoutlined/<名称>_24px.svg`

| 名称 | 使用位置 |
| --- | --- |
| `dashboard` | 听歌概览导航 |
| `leaderboard` | 听歌排行导航 |
| `calendar_month` | 年度足迹标题与日期对话框 |
| `lightbulb` | 听歌小结标题 |
| `queue_music` | 歌曲播放次数标题 |
| `download` | 导入 |
| `upload` | 导出 |
| `search` | 歌曲搜索 |
| `dark_mode` | 深色主题模式 |
| `light_mode` | 浅色主题模式 |
| `routine` | 跟随系统主题模式 |
| `expand_more` | 下拉选择箭头 |
