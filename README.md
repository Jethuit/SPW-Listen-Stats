# SPW 听歌统计

面向 Salt Player for Windows 的听歌统计模组。目前提供第一版前端交互预览，尚未连接播放器。

## 查看预览

直接用浏览器打开 `preview/index.html`。不需要安装 JDK、安装依赖或联网加载资源。

页面顶部提供“听歌概览 / 听歌排行”导航：概览展示时长统计、热力图、趋势图和听歌小结；排行独立展示逐首歌曲播放次数。可使用 `preview/index.html#ranking` 直接打开排行页，切换页面会保留当前导入数据和筛选条件，并支持浏览器前进、后退。

预览包含：

- 累计听歌时长、听歌天数、最长连续和当前连续，不统计总播放次数。
- 年度听歌时长热力图，支持年份选择、悬停详情和键盘方向键导航。
- 近期、本月、自定义日期范围，以及按日、按周、单日按小时的趋势图。
- 点击热力图某一天，联动查看当天的小时分布。
- 独立的听歌排行页，按歌曲 ID 独立累计播放次数；支持按歌名或歌手搜索、按播放次数或名称排序。同名歌曲也各自保留。
- 明暗主题、简单听歌小结、图表数据表。
- 预览数据的 JSON 导入导出。

## 示例数据

所有数字均为示例数据，歌曲、歌手和专辑名称为虚构，演示日期固定为 **2026-10-18**。导入只替换当前页面内存中的预览数据，刷新页面会恢复示例记录；不写入播放器，不读取用户的音乐文件。

热力图和趋势图仅展示听歌时长。歌曲列表展示每首歌的累计有效播放次数，不受上方年份与日期筛选影响，不计算跨歌曲的总次数。

当前导出格式为版本 2，逐日时长 `records` 与逐首次数 `tracks` 分开保存。旧版预览文件可以导入收听时长，但其每日总次数无法还原到每首歌曲，因此不会生成或推算逐首次数。

预览 JSON 是独立的演示格式，不能当作正式模组备份。后续真实统计按“同一次播放实际听满歌曲时长的 50% 为该歌曲计一次”实现；暂停和跳过的进度不计入听歌时长。

## 目录

```text
preview/       无依赖的 HTML / CSS / JavaScript 交互预览
.references/   上游参考源码，仅在本地保留，不提交 Git
```

这个阶段用于确认布局和交互。HTML 是设计原型；正式模组计划使用 Kotlin / Compose 和原生 Salt UI，具体主页嵌入方式还需要在 SPW 1.19.0 中验证。
