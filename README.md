# SPW 听歌统计

面向 Salt Player for Windows 的听歌统计模组。目前提供第一版前端交互预览，尚未连接播放器。

## 查看预览

直接用浏览器打开 `preview/index.html`。不需要安装 JDK、安装依赖或联网加载资源。

预览包含：

- 累计时长、有效播放次数、听歌天数、最长连续和当前连续。
- 年度热力图，支持年份选择、悬停详情和键盘方向键导航。
- 共用的“听歌时长 / 播放次数”切换，同时更新热力图和趋势图。
- 近期、本月、自定义日期范围，以及按日、按周、单日按小时的趋势图。
- 点击热力图某一天，联动查看当天的小时分布。
- 明暗主题、简单听歌小结、图表数据表。
- 预览数据的 JSON 导入导出。

## 示例数据

所有数字均为程序生成的示例数据，演示日期固定为 **2026-10-18**。导入只替换当前页面内存中的预览数据，刷新页面会恢复示例记录；不写入播放器，不读取用户的音乐文件。

预览 JSON 是独立的演示格式，不能当作正式模组备份。后续真实统计按“同一次播放实际听满歌曲时长的 50% 计一次”实现；暂停和跳过的进度不计入听歌时长。

## 目录

```text
preview/       无依赖的 HTML / CSS / JavaScript 交互预览
.references/   上游参考源码，仅在本地保留，不提交 Git
```

这个阶段用于确认布局和交互。HTML 是设计原型；正式模组计划使用 Kotlin / Compose 和原生 Salt UI，具体主页嵌入方式还需要在 SPW 1.19.0 中验证。
