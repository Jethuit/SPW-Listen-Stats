# 听歌统计模组源码

Kotlin / Compose / Salt UI 实现，当前源码版本为 v0.2.6-dev.9，基于 SPW 1.19.2 构建，采用运行时结构发现接入宿主。安装与功能介绍见[项目首页](../README.md)，产品规则见[需求](../docs/REQUIREMENTS.md)，依赖与许可证见[第三方组件](../docs/THIRD-PARTY.md)。

## 目录

- `plugin/`：正式模组源码和随包资源。
- `preview/`：已确认的 HTML 视觉基准及本地素材；可直接打开 `preview/index.html`。预览使用演示数据，旧版控件与正式模组有差异，后续确认的需求优先。
- `tests/`：数据回归、包结构和离屏视觉检查。
- `tools/`：工具链准备、构建与发布包整理脚本。
- `docs/`：当前需求、第三方声明、正式发布说明和效果截图。
- `build/`：忽略提交的工具链、安装包、合成测试状态和检查结果。

## 构建

在仓库根目录执行，按本机安装位置修改 `--spw-dir`：

```powershell
py -3.12 tools/prepare_toolchain.py --spw-dir "E:\SteamLibrary\steamapps\common\Salt Player for Windows"
py -3.12 tools/build_plugin.py --spw-dir "E:\SteamLibrary\steamapps\common\Salt Player for Windows"
```

构建使用 JDK 25、缓存的 Kotlin 编译器、SaltUI 及对应宿主 jar。每次构建比较安装目录与缓存宿主文件的内容，更新后自动刷新缓存，避免相同文件大小的宿主更新被漏过。工具链缓存位于 `build/tools/`，不提交 Git。版本号以 `tools/build_plugin.py` 的 `PLUGIN_VERSION` 为准；当前开发包为 `0.2.6-dev.9`，正式版 `0.2.5` 保持不变；安装包输出到 `build/libs/SPW-Stats-v<版本>.spmod`，解包目录为 `build/install/spw-listen-stats/`。

宿主随附的 Kotlin 模块信息缺少部分 Compose 顶层函数索引。构建通过 `tools/RestoreComposeIndex.java` 从当前宿主类的 Kotlin 注解重建运行时包及明细所需的点击、焦点、惰性列表和滚动条编译索引，输出 `build/tools/spw-compose-compile-index.jar`；不需要旧宿主，也不修改安装文件。该文件只用于编译，不进入 `.spmod`，运行时仍使用宿主 Compose 类。

默认只生成本地产物，不安装或发布。通过 SPW 创意工坊／模组管理本地导入 `.spmod` 并授权 `library-read`、`class-transform`。`py -3.12 tools/prepare_release.py` 仅将当前包整理到 `build/releases/v<版本>/`，不会上传 GitHub。

源码变化不会自动更新已有安装包，需要重新构建。

亚克力深色模式的卡片与共用控件底色统一为不透明的 `#5F5F5F`，覆盖累计统计、听歌小结、歌曲明细、日期及提示卡片，避免背景变化造成灰色偏亮。页面仍继承宿主材质；浅色主题和云母等其他材质保持原配色。

热力图标题下方仅显示所选范围的听歌日数和总时长，年份或“近一年”统一由右侧选择框显示。

深色热力图的四档蓝色已提高亮度，由低到高使用 `#3F78AE`、`#5799D6`、`#7AB7EC`、`#A5D4FF`，保留收听越多越亮的方向。每日与每周共用新配色；浅色主题、空白灰格和统计分档不变，真实材质下的观感需安装开发包核对。

图表下方默认显示灰色小字“点击柱子或曲线查看歌曲明细，再次点击收起”。点击时长分布的柱子、折线或曲线对应时段，在图表下方展开歌曲明细，支持 300ms 展开／收起动画及全局动画开关；再次点击当前时段收起，点其他时段直接更新，右上关闭按钮或图表／卡片内 Esc 收起。列表按本时段时长排序，默认最多显示六行，可配置为3～12行，超出时在卡片内滚动。后台读取同一统计快照中的合并事件，普通刷新保留当前明细，改变日期范围或粒度后收起。明细总时长、歌曲时长和无法关联时长显示到秒，显示已累计的完整秒数，不足一秒显示“不足1秒”；其他页面保持分钟显示。删除歌曲旁的“含近似记录”标注，保留卡片底部的近似时段说明；旧版汇总无法关联歌曲的时长单列说明，不推算时段播放次数。周期对比、范围榜单、分享卡片目前仍只在审核预览中。

当前开发版取消小时折线／平滑曲线首尾补出的水平延长线，填充在真实端点处向下闭合，保留半个区间留白及原有线条端头样式。顶部导航首项去除左内边距，与累计卡片和热力图等正文左边缘对齐，蓝色下划线仍跟随图标与文字内容。

时长分布首次默认“今天＋柱状图”，已有日期范围和图表类型仍按保存值恢复；热力图取消框选后回到今天。排行工具栏采用“标题／艺术家／专辑”菜单，分别对应歌曲、歌手、专辑的播放次数排行。

模组配置支持“排行每页数量”（正整数输入，默认 25，无效输入回退默认值）和“页面动画”（默认开启，整页进入／退出采用 SPW 桌面弹簧，内部导航及排行切换仍为 300ms，搜索框按原生 90ms 淡出／延迟后 300ms 淡入与缩放切换，热力图从左往右逐列显现 650ms）。设置在重新打开统计页或下次自动刷新时读取；更改每页数量后回到第一页。动画关闭只改变界面切换，不影响收听记录。

另提供四项自定义设置：

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 页面刷新间隔（秒） | 5 | 允许2～60的整数，仅调整页面更新频率，不改变收听记录。 |
| 明细可见行数 | 6 | 允许3～12的整数，超出的歌曲在明细卡片内滚动。 |
| 显示明细操作提示 | 开启 | 控制图表下方提示小字，隐藏后仍可点击查看明细。 |
| 热力图展开动画 | 开启 | 可独立关闭逐列显现；只有页面动画总开关也开启时才播放。 |

数值为空、类型错误、非整数或超出范围时回退默认值。设置保存到本机配置，在重新打开统计页或下次自动刷新时读取；修改刷新间隔时，当前等待仍按旧间隔结束，之后使用新间隔。普通刷新保留当前明细和筛选状态。

## 接入与数据

- 顶部听歌统计图标和模组配置的“打开听歌统计”共用入口。页面经宿主 Hook 嵌入内容区，保留侧栏和播放栏；Hook 与宿主内部签名绑定，升级 SPW 后须核实兼容性。
- 从 v0.2.4 开始，每次启用在后台读取当前宿主文件，按 Compose／Navigation3 调用、签名和状态访问关系发现页面、标题栏、导航与深浅主题，不再按版本选择混淆类名，也不沿用上次扫描结果。统计页外侧的 Salt Layer、三套桌面弹簧转场、返回时的播放器展开／弹窗判断使用专用结构规则。匹配缺失、歧义或调用点不唯一时拒绝相关接入，核心 Hook 安装失败整组撤销；标题栏可单独降级到配置入口。UI 失败保留公开播放回调记录，核心页面失效时配置入口仍无法打开，不提供独立窗口。
- 停用会取消后台扫描，忽略已过期的结果并清理本次反射对象和 Hook，不等待扫描结束。宿主响应式主题读取失败时保留原有宿主设置／系统主题降级方式；窗口材质和字体仍按防御性配置读取。此机制主要应对名字变化，内部结构、Compose／Workshop API 或数据库变化仍需适配；静态发现与宿主解析器通过不代表实机注入、AOT、DWM 和多插件共存已经验收。
- 明确返回才向下滑出并淡出；直接切页时统计原位淡出，目标页在其上层滑入覆盖，两个动画同时发生。进入统计／明确返回时原宿主页原位淡出／淡入，统计显示期间宿主正文不接受操作。侧栏、替换及前进请求继续通过完整 Hook 链，在原导航实际被接受后的回调中开始覆盖转场。例如“专辑 → 统计 → 歌曲”不应再经由专辑。其他插件延后或取消离开时保持统计，确认重放后再切换。转场期间屏蔽统计控件、收起弹层，重新打开会取消视觉退出；已经被宿主接受的导航不回滚，结束回调也不重放导航。禁用或卸载立即清理。导航标签不绘制悬停灰底。
- 启用后后台预读统计与偏好，首次无快照时保留宿主页，准备完成后经过原有导航离开保护再打开完整统计页。再次打开使用本次启用期间最近快照，后台读取最新数据。其他导航、返回、关闭及停用使等待中的打开请求失效；禁用取消预读并丢弃会话缓存。首次读取失败以错误页面处理，不冒充真实空数据。
- 页面打开时立即后台刷新，随后按配置间隔刷新（默认5秒，2～60秒）；进入过程中读完的结果等实际弹簧完成才应用，不靠固定延时。导入后的刷新走同一串行读取通道；刷新失败保留上次成功数据并显示错误，下一次成功清除错误。普通刷新不退回占位、不重播整页或热力图显现，保留当前筛选、滚动及可用页码。缓存仅保存在内存，首次进入速度仍取决于实际数据库读取时间。
- 宿主外观在后台发现阶段预读，并由常驻内容层更新；材质接入通过组合上下文提供，避免首帧依赖稍后才执行的效果而先画实色。亚克力／云母页面进入时，对照 2026-10-23 原生录像采用完整旧页原位淡出，取消随新页上边缘移动的硬裁剪；允许动画期间短暂叠显，淡出完成后隐藏旧页。明确返回和直接切页保留原行为。完整淡出与稳定后的隔离可用合成背景离屏检查，真实 DWM 仍需录屏核对。
- 宿主历史来源于内部 `Listen` 数据表的只读查询，受保留范围和表结构影响；实时会话由播放回调记录。单次加载合并宿主、实时与导入事件后统一聚合。
- 实际收听按单调时钟计量，并按墙钟区间拆分日期和小时。暂停与拖动跳过的进度不计时，同一遍播放最多计一次；达到歌曲时长的 50% 才计为有效播放。
- 同一会话的精确收听片段按区间并集合并，宿主近似快照单独处理，不能直接相加。当前备份 v2 保留会话身份，兼容旧 v1 汇总的保守合并；旧汇总可能少计。
- v0.2.3 合并时固定保留精确片段的位置，总量取精确片段并集与最长宿主快照的较大值；仅将不足的差额按宿主区间未被精确片段覆盖的部分近似分配。精确证据仍独立保存，重复导入不移动已知片段。本机已否定的宿主关联在导入、聚合和导出合并前过滤，防止旧备份恢复错误关联。元数据优先使用当前曲库的有效字段，其次已有本机／实时信息，历史备份只填空缺；跨库身份仍隔离。
- 公开 Workshop 播放 API 没有当前播放状态查询。中途启用时，在曲目身份稳定且进度连续合理前进后建立初始播放状态，只记录观察到的后续片段；不补算启用前的时间。明确的暂停、停止、缓冲与拖动回调仍使旧计时基线失效。
- 返回 Hook 保留宿主弹窗和展开播放器的处理优先级；无动画导航也只在原请求未被跳过且未抛错后关闭统计。普通同页导航会使旧的延后打开请求失效。热力图在退出时清理提示并停止选择，且不响应父层已消费的按下事件。
- 本机来源身份用于隔离曲库 ID。跨设备或重建曲库后不按同名歌曲强行对应；未知播放起点、插件启用前的片段及已丢失的旧记录不能可靠补回。
- 封面取自内嵌图片，成功结果有容量受限缓存，空封面与失败请求分别冷却重试；异库曲目 ID 不查询本机封面。
- 热力图自动按最近 12 个月的非零日／自然周时长分别计算四分位颜色阈值，切换查看年份不改变基准；零时长保持灰色，相同时长保持同色，少量或重复样本不强行凑齐四档。已移除手动热力门槛设置，旧值忽略；每周柱高仍按所看范围峰值计算。
- 始终跟随宿主深浅主题。支持材质的页面继承宿主背景，接入不可用时回退实色；真实 DWM、播放回调时序及多插件共存仍需实机核对。
- v0.2.2 将页面隔离移到承载 AppNavigation 的原生 Salt Layer 内容内，保留 Layer 的 Modifier、装饰开关与原始内容调用，统计页在隔离层外组合。这样不争用歌词插件的 AppNavigation 替换位置，也能管理它在该位置外层绘制的工具页。统计稳定显示时宿主内容保留组合但不放置；直接切页时同一宿主内容层升到统计页上方，目标开始覆盖进入，转场期间阻止正文操作，宿主组合不因层级变化重建。
- 歌词插件发出的同页导航是同步打开页面前的通知，不能在动画结束后再次回放，否则会触发它的离开保护并关闭新页面。此类工具页不经过 NavDisplay，内容层提供 150 像素的弹簧滑入；真实宿主路由直接使用其自身的进入动画，避免双重位移。快速返回统计仍请求对方离开；视觉退出及组件卸载不取消较新的待确认请求，确认后再打开统计，取消则留在目标页。所有跳转直接通过原导航链，不保存延迟导航闭包。
- 统计入口经宿主导航请求其他工具页离开，等待歌词插件的未保存确认后再显示，取消不切页。请求使用当前宿主路由的等值副本，以独立身份关联延迟回调；在优先级 50 处消费，优先级 100 的普通导航观察器负责取消旧请求，其间允许歌词插件的优先级 80 离开保护执行。不会插入自定义统计路由；同页请求仍保留 SPW 1.19 原生的无操作语义。检查使用模拟离开保护、宿主真实 navigate 方法和隔离渲染，真实双插件及 DWM 仍需实机验收。
- 宿主标题栏的内容模糊由 Salt UI BasicScreen 和 Haze 实现：正文作为 hazeSource，标题栏叠加 hazeBlur；Windows 默认 Mask 模式为 8dp 半径、无噪点与纵向渐变遮罩。它与亚克力／云母窗口背景材质属于不同层；当前统计页正文仍裁在标题栏下面，尚未接入这层内容模糊。

### 宿主整页导航动画

本机 SPW 1.19.1 安装文件的 `AppNavigationKt`、`Navigator`、Navigation3 与 Compose 字节码可确认以下机制；缓存的 1.19.0 中三套桌面转场参数相同。这是普通页面导航的实现，弹窗、Sheet、搜索控件及列表自身的动画另行处理。

- 调用链为 `Navigator` 更新 `NavBackStack` → 路由对应 `NavEntry` → `SceneState` → `NavDisplay` → `SeekableTransitionState` / `Transition` → `AnimatedContent`。外层 `SharedTransitionLayout` 提供共享元素作用域，不表示每次切页都执行共享元素动画。
- Windows 选用 `voxzenTransitionSpec`：新页从 `IntOffset(0, 150)` 滑入，旧页原位淡出；新页没有额外的整页淡入。返回选用 `voxzenPopTransitionSpec`：上一页原位淡入，离开的页面向 `IntOffset(0, 150)` 滑出并淡出。桌面的预测返回使用相同动画组合。
- 位移为直接构造的 150 个布局像素，不经过 dp 转换，也不按页面高度取比例。位移和透明度均使用 `spring(stiffness = 500f)`，默认阻尼比为 1，属于临界阻尼；500 是刚度，不是毫秒。动画完成时间由弹簧收敛、阈值及中断状态决定。
- 普通导航与返回的转场同时处理进入页和退出页。`NavDisplay` 维护场景键和层级：前进时新页高一层，返回时恢复页低一层；主场景的 `sizeTransform` 为 null，不采用插件内部切页的尺寸补间。动画运行时主场景生命周期上限为 STARTED，稳定且无覆盖场景时恢复 RESUMED。
- 每次目标场景变化由 `LaunchedEffect(scene)` 驱动同一份可中断转场状态；返回当前场景时按已有进度回退或完成，不通过固定延时排队。`AnimatedContent` 按内容键复用仍存在的页面，并在退出完成后移除旧内容；`NavDisplay` 在转场停止后清理旧场景及层级记录。可保存状态由 `SaveableStateHolderNavEntryDecorator` 按内容键保存，顶层页面被移出返回栈时保留其可保存状态；这与让所有旧页面永久留在组合中不同。
- `Navigator.navigate` 对与当前路由相等的请求直接返回；顶层导航清除子页面并替换根路由，普通子页面追加到栈。Navigation3 通过旧、新内容键栈的前缀关系识别返回，未按侧栏位置决定左右方向。
- 同一文件中的 iOS 分支采用 500ms 横向转场、四分之一宽度的背景视差与暗幕；Windows 不走此分支。Navigation3 随附的桌面默认转场本身为 None，SPW 显式传入上述自定义组合。

统计整页通过稳定的 Compose `Animatable` 实现同款桌面转场：150 个布局像素的 `IntOffset` 弹簧与独立透明度弹簧，刚度 500、阻尼比 1，沿用 Compose 的类型转换与默认弹簧收敛阈值。首次进入只滑入，明确返回滑出并淡出，直接切页原位淡出且目标显示在上层；页面背景包含在运动外壳内。原宿主页的淡出／淡入共享同一轮动画任务，弹簧完成后清理统计页，不依赖固定延时。反向打开会取消旧任务，从当前值继续；关闭动画时直接到达目标。概览／排行等内部切页仍为 36dp 横移与 300ms `AnimatedContent`。

统计页与歌词插件工具页仍在原生路由之外组合，没有注册宿主内部路由，因此不具备完整的 NavDisplay 场景生命周期或预测返回。直接从统计切往真实路由时，临时适配 `AppNavigationKt` 三个桌面转场工厂的退出部分：保留其进入动画、层级及尺寸设置，让底层更早的宿主场景立即淡出，避免它盖住统计。普通宿主导航、进入统计和明确返回均保持原工厂结果。该适配按当前宿主结构发现并随插件撤销；新 Hook 的实际注入、窗口帧率、背景材质及跨插件视觉效果仍需实机核对。

### 数据目录与诊断

数据通常位于 `%APPDATA%\Salt Player for Windows\workshop\data\com.jethuit.spw.listenstats\`；有宿主插件路径时按该安装的数据根目录解析。实时文件为 `live-sessions.json`，导入数据为 `imported.json`，来源身份为 `source-id.txt` 及冗余副本。配置页“写入诊断日志”将状态写入该目录的 `status.log`，成功提示包含实际路径；数据目录不可用时日志可回退系统临时目录。

宿主自附加 Agent 在部分非 ASCII 路径下的安装失败尚未解决；该问题不能通过插件 Manifest 的 UTF-8 折行修复来解释。
