# 统计入口位置

配置页增加“在左侧栏显示统计入口”，配置键为 `sidebarEntry`，默认关闭。

- 关闭：顶部显示原来的统计图标。
- 开启：在音乐库后的扩展入口区域、设置之前显示“统计”，隐藏顶部图标。
- 约 750 毫秒在后台读取保存后的设置，通过当前启用会话更新 Compose 状态，无需重启。读取失败保持最近成功的位置；停用取消读取并使旧回调失效。
- 两处入口共用 `StatsNavigationHooks.openStats`，保留已有快照准备、离开保护及退出动画。
- 左侧栏接入不可用时保留顶部入口；顶部接入不可用时可使用左侧栏入口。配置页的“打开听歌统计”继续保留。

## 接入依据

参考 [Salt-Extend-Online 的原生侧栏接入说明](https://github.com/YGHFv/Salt-Extend-Online/blob/82bd30e9efd77ab8746a82da26386970018f6813/docs/NATIVE_UI_PROGRESS.md)，参考提交为 `82bd30e9efd77ab8746a82da26386970018f6813`：在原生 SidebarRouteItem 的唯一 lazy-item 调用后使用 Workshop `afterComposable` 追加内容，仅对 MusicLibrary 项绘制扩展入口。

本项目根据本机宿主字节码独立定位 route 行、公开访问器、调用者、route getter 和 SidebarItemLayout；不固定混淆名称。沿用原生行布局及其 SidebarItemStyle，图标使用本插件现有统计 SVG。保留宿主原来的行与其他扩展入口，Hook 优先级为 25。页面仍采用本项目原有统计页接入，不移植参考项目的页面路由或在线功能。

入口描述加入当前宿主目标缓存，当前格式版本为 3，继续按宿主路径、摘要及插件版本校验；缺失或歧义作为可选入口失败，不阻止核心统计页面接入。两种位置通过可观察状态切换，不反复安装和卸载 Hook；停用时正常释放所有句柄。

## 选中状态

统计页使用原有宿主路由作为底层页面。左侧入口显示且统计页打开时，在侧栏唯一的单值 `CompositionLocalProvider` 调用点提供原生 SidebarItemStyle 的未选中副本：文字色和文字样式使用普通状态，选中背景使用普通背景，关闭选中指示条。原样式对象保持原值。进入与退出统计共用同一 Provider 调用点、相同数量的 Local 和同一内容调用；统计行也始终使用固定的局部 Provider。切换仅更新样式值，保留侧栏组合、列表状态和已启动效果，避免整栏卸载重建。统计行在自身范围恢复原样式，因此只显示统计项的选中效果。宿主栏目、歌单和复用该 Local 的扩展行都在同一侧栏作用域内；离开统计、停用或切换回顶部入口后自动恢复原样式。导航路由、历史与点击回调沿用原流程。

样式接入使用无默认参数 mask 的 Provider 调用点，与追加入口作为同一可回滚 Hook 组注册；样式能力不可用时，侧栏入口整体降级到顶部入口。

## 验证边界

`tests/check-entry-placement.py --ui-only` 可集中编译并只检查侧栏交互、组合生命周期及包结构。完整的 `tests/check-entry-placement.py` 集中构建并检查设置读取、实时切换、读取失败、缺失入口降级、启停会话隔离、原生侧栏渲染与点击、结构重命名和目标缓存，以及当前宿主的真实 Hook 解析器。检查在 `build/tests/` 的隔离配置中运行，不安装插件、不操作真实曲库、队列或听歌记录。

实机入口排序、不同主题和缩放，以及与其他插件同时运行的效果，由用户安装开发包确认。
