# 0.1.25 排行分页显示

2026-10-19。处理 600+ 首歌曲时右下角分页的显示。

## 规则

- 每页仍为 **25 首**。
- 600 首全集 = `ceil(600 / 25) = 24` 页；最后一页 16 首。
- 右下角现在显示 `第 1 / 24 页`，右侧分页按钮不会列出全部 24 个数字，而是：
  - 当前在第 1–3 页：`1 2 3 4 … 24`
  - 当前在中间页：`1 … 11 12 13 … 24`
  - 当前在最后三页：`1 … 21 22 23 24`
  - 总页数 ≤7：全部显示。
- 首页/末页、当前页始终可见；`…` 表示省略的页段；`‹`/`›` 前后翻页。
- 分页总数使用**当前筛选结果**：搜索后从 600 首缩到 20 首时，显示 `第 1 / 1 页`，分页自动隐藏。
- 空结果没有分页，底部仍显示 `共 0 首 · 听满单曲 50% 计一次`。

## 说明

没有把 600 首全部平铺成 24 个按钮，因为右下角宽度有限且会挤压左侧说明；使用“首尾 + 当前邻域 + 省略号 + 第 x / y 页”是固定宽度、任意歌量都可用的方案。
