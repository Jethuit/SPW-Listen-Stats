# 0.1.31 分页居中、跳页与底部保持

2026-10-19。处理分页在底部的滚动位置，以及底栏布局。

## 一、切页时保持底部

之前的修复只是移除了 `scrollTop()`，导致从最后一页（行数少）切回整页（25 行）时，滚动值停在旧高度，看起来“没到底”。

现在：

1. 点击分页前记录是否已经接近底部（`value >= maxValue - 2`）。
2. 只有原本在底部时，切页后等待新页面布局（60ms），再 `scrollTo(maxValue)`。
3. 原本不在底部时保持原滚动偏移，不会跳顶，也不会被强行拉到最底。

## 二、底栏布局

```text
共 53 首 · ...         [ 1  2  3 ]        共 3 页 · 跳转至 [1] 页
```

- 页码按钮组用左右等权占位盒子夹住，水平居中。
- 左侧保留总数说明。
- 右侧显示总页数与跳页输入框。
- 输入页码后按 Enter 跳转；自动 clamp 到 1..总页数。
- 页数变化时输入框跟随当前页重建。
- 单页时仍显示“共 1 页”，不显示跳页输入。
