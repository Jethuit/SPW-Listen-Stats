# v0.1.4：宿主材质适配记录

## v0.1.4-dev.3：浅色亚克力颜色校准

2026-10-20 用户提供原版亚克力聚焦、失焦截图，以及 dev.2 概览和排行截图，要求先逐项优化亚克力，另外两种材质随后处理。本次只校准这组浅色亚克力参考，不改布局或窗口效果。

- 参考图的失焦页面底色为 `#DDDDDD`、卡片内部为 `#E2E2E2`、细边框为 `#C7C7C7`；dev.2 卡片约为 `#F2F2F2`，透明度不足。卡片改用 16% 白色覆盖，与聚焦的蓝色背景自然合成，失焦时由宿主提供灰色底层，不另做焦点轮询或固定灰背景。
- 边框、列表分隔线和图表网格改用 28% 中性灰 `#808080`。主文字参考原版 `#1E1715`，次要文字采用 56% 黑色，让文字随实际背景合成；卡片和边框不同于页面透明色。
- 控件底色、悬停底色与无收听热力格采用低透明度黑色，替换原先大面积偏白的不透明颜色；分组按钮与分页的选中填充单独使用半透明白色。热力图有效听歌等级继续使用原有蓝色，未来日期继续降低可见度。
- 不改变弹出菜单、日期对话框、提示卡的实色底，避免多层半透明影响阅读。云母、云母 Alt、深色亚克力沿用 dev.2；手动浅／深模式和经典主题保持原调色板。未提供深色亚克力参考，不能声称其颜色已精确校准。

检查使用实际 SummaryStrip、SegmentedControl、SelectBox 和 YearHeatmap 组件，在三个取样的平面背景上合成，比较原版卡片和边框颜色；这是模拟合成检查，不是 Windows DWM 截图。用户提供的实机图证明 dev.2 已能显示背景和失焦变化，dev.3 的最终观感仍由用户核对。

本轮集中验证：40 个 Kotlin 文件构建成功，8/8 组 UI 检查通过，包含云母／云母 Alt／深色亚克力保持 dev.2 输出、手动模式和经典模式保持原样；三张实际组件合成图通过。聚焦卡片分别渲染为 `(204,224,240)`、`(181,220,254)`，与参考样本各通道误差不超过 2；失焦卡片为 `(226,226,226)`，边框为约 `(199,199,199)`，空白热力格确认不再使用不透明经典色。原生合成图已查看，未重复数据层或导航测试。

开发包：`build/libs/SPW-Stats-v0.1.4-dev.3.spmod`，17,247,002 字节、162 项，结构检查通过、无新增权限。保留 dev.1 数据修复及 dev.2 材质入口；未上传或发布，公开版本仍为 v0.1.3。

## v0.1.4-dev.2：宿主材质初步适配

日期：2026-10-20。用户确认适配亚克力、云母、云母 Alt；仅在插件主题为“跟随 SPW”时使用宿主材质，手动浅色、深色保留纯色背景。

## 接入方式

- 继续使用原有 `AppNavigation` 后追加统计页的入口。新增可选的调用点替换，原导航仍在插件包装层中调用，页面组合及状态保留；打开统计页时不放置底层内容，因此不绘制、不参与鼠标命中。关闭后恢复放置，不重新创建整个导航。
- 替换只作用于宿主调用类 `androidx.compose.ui.ۄ` 的调用点；插件自身对原 `AppNavigation()` 的调用位于不同类，不参与替换。已用本机 SPW 1.19.0 头文件和 Workshop Hook 文档核对，但真实宿主重写与材质合成仍需实机验收。
- 只有包装层实际进入组合、材质为三种已知 Windows 样式且选择“跟随 SPW”时，统计页底色才透明。卡片、控件采用带色调的半透明填充；弹出提示保持不透明。DWM 效果由宿主主窗口提供，插件不设置全局窗口特效、不另开材质窗口。
- 可选 Hook 不可用、被其他替换覆盖、读取不到材质、非嵌入入口或手动浅深模式时，保留经典纯色背景。避免透明页露出宿主歌曲列表。
