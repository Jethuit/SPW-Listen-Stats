# v0.1.4-dev.2：宿主材质初步适配

日期：2026-10-20。用户确认适配亚克力、云母、云母 Alt；仅在插件主题为“跟随 SPW”时使用宿主材质，手动浅色、深色保留纯色背景。

## 接入方式

- 继续使用原有 `AppNavigation` 后追加统计页的入口。新增可选的调用点替换，原导航仍在插件包装层中调用，页面组合及状态保留；打开统计页时不放置底层内容，因此不绘制、不参与鼠标命中。关闭后恢复放置，不重新创建整个导航。
- 替换只作用于宿主调用类 `androidx.compose.ui.ۄ` 的调用点；插件自身对原 `AppNavigation()` 的调用位于不同类，不参与替换。已用本机 SPW 1.19.0 头文件和 Workshop Hook 文档核对，但真实宿主重写与材质合成仍需实机验收。
- 只有包装层实际进入组合、材质为三种已知 Windows 样式且选择“跟随 SPW”时，统计页底色才透明。卡片、控件采用带色调的半透明填充；弹出提示保持不透明。DWM 效果由宿主主窗口提供，插件不设置全局窗口特效、不另开材质窗口。
- 可选 Hook 不可用、被其他替换覆盖、读取不到材质、非嵌入入口或手动浅深模式时，保留经典纯色背景。避免透明页露出宿主歌曲列表。

## 验证范围

检查脚本放在 `tests/`。模拟背景可以验证底层内容隐藏、鼠标命中、状态保留、返回显示和透明页的合成关系；无法证明 Windows DWM 模糊、桌面壁纸取色、失焦与节能模式下的最终效果，也不能冒充 SPW 实机截图。

本地验收应在 SPW 1.19.0 分别切换亚克力、云母、云母 Alt，检查概览与三种排行、返回、侧栏跳转、窗口缩放及浅深模式。未对卡片透明度承诺与宿主像素级一致。

本轮集中检查通过：40 文件构建成功，UI 回归 **8/8**、导航回归 **7/7**；`MaterialLayerVisualCheck` 确认原组件仅创建一次、隐藏期间不接收点击、恢复后仍可点击，合成图像的透明区域显示模拟背景而非隐藏页面。包结构检查通过（162 项、17,246,483 字节），无新增权限。未运行真实 SPW 材质测试，模拟结果不代表已完成 Windows DWM 实机验收。

开发包：`build/libs/SPW-Stats-v0.1.4-dev.2.spmod`，同时包含 dev.1 的两项数据修复。当前公开版本仍为 v0.1.3；README 继续描述公开版本。
