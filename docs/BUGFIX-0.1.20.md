# 0.1.20 审查问题修复

2026-10-19。基于 0.1.19 审查发现的六项问题，保留内嵌页面、配置页入口、25 首分页和经典底色。

## 改动

1. **会话恢复**：只在初始化后的首次有效播放观察中尝试恢复一次；观察到其他歌曲后，旧的未完成会话会结束并保存。显式从头播放、停止或正常停用也会关闭遗留会话。修复“崩溃前 A → 重启后 B → 新一遍 A”把两遍 A 合并的问题。首次观察仍为同一首歌时，缺少宿主会话身份的歧义依然存在。
2. **时钟校正与备份**：实际时长继续取单调时钟；回拨产生的片段起点不早于前一片段终点，受影响的会话标为 approximate。读取旧实时文件时也修整重叠片段，保留顺序和累计时长，避免旧记录持续阻塞导出。校正附近的小时分布只能近似，不声称还原了准确墙上时间。
3. **滚动悬停**：内嵌页将 SaltUI 滚动位置传入 LocalViewportRevision，热力图、趋势图和控件悬停状态随实际滚动失效。
4. **文字字体**：新增 StatsText，在 SaltUI 当前文字样式上合并页面字号、字重和颜色；正文、提示框、排行和搜索输入框不再丢弃继承的字体族。宿主字体能否完整传入插件 SaltUI 作用域仍需实际验收。
5. **搜索排名**：全榜排序后先分配排名，再搜索和分页；搜出第 80 名仍显示 80，搜索摘要继续显示筛选结果的位置。
6. **日期无关测试**：findOpen 支持传入当前时间；测试固定传入模拟时钟，并覆盖六小时有效期过期，不再依赖运行当天。
