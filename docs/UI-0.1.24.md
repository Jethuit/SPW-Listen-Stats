# 0.1.24 热力图近一年、短自定义标签与最小窗口不换行

2026-10-19。基于 0.1.23，按反馈修正热力图菜单、范围菜单文案、自定义按钮文案和最小窗口布局。

## 一、热力图“近一年”

- 热力图年份菜单新增 **近一年**，与具体年份并列。
- `HeatmapGrid` 增加 rolling 模式：起始 `today - 364 天`，结束 `today`，按周一对齐，显示最近 12 个月的月标签。
- 标题下方改为 `近一年 · x 个听歌日 · x 小时`；切回具体年份后恢复 `2026 年 · ...`。
- 日/周视图、选中日期、悬停/点击均按滚动区间判断，不再按 `date.year` 截断。
- 选择“近一年”只影响热力图浏览，不改变榜单/时长分布的日期筛选。

截图：`build/screenshots/heatmap_menu_final.png`（菜单含近一年）、`build/screenshots/heatmap_rolling_final.png`（近一年热力图）。

## 二、范围菜单文案

- `RangePreset.Custom.label`：`自定义日期` → **自定义**。
- 时长分布的自定义范围按钮不再显示 `2026年8月13日–2026年10月17日`，统一显示 **自定义**。
- 具体某天的 `所选日期` 仍显示该日期。

## 三、最小窗口按钮不换行

`SectionHeading` 不再在 `maxWidth < 600dp` 时把标题和操作区改成上下两行，也不再使用 `FlowRow` 自动换行：

- 标题在左，操作按钮/搜索框在右，保持单行。
- 标题可占剩余宽度；操作区不换行。
- 日期范围按钮改为短“自定义”后，最小窗口下 3 个图表类型按钮 + 范围 + 粒度也能容纳。
- 截图：`build/screenshots/min_layout_final.png`（1000×900 窗口，热力图和时长分布的标题/操作区均同行）。

## 四、验证

- 1000×900 宿主窗口截图：热力图“每天/每周/2026年”同行；时长分布图表按钮/范围同行；无换行。
- 热力图菜单实际打开：近一年 + 2026年，菜单宽度与触发按钮一致；点击“近一年”标题和网格切换为滚动 12 个月。
- 未测：最小窗口下打开完整自定义范围弹窗、键盘 Esc/非法范围、真实滚动 FPS。
- 35 个 Kotlin 文件构建通过；18 组数据回归、6 组 UI 回归通过。
- `.spmod` 129 项结构检查通过；权限仍为 `library-read`、`class-transform`。
- 产物：`build/libs/plugin-com.jethuit.spw.listenstats-0.1.24.spmod`（17,150,118 字节）。
