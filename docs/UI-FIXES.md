# UI 修订

## 0.1.5 宿主内嵌 + SaltUI

用户指出独立无边框窗口不能拖动、看起来永远置顶，且右下角浮动 pill 会盖住宿主按钮。已改为：

- 删除 `JDialog` 展示路径和 `Popup` pill；`StatsOverlay` 直接在 `AppNavigation` hook 的宿主编排中渲染页面。
- 内嵌页面占宿主右侧内容区，保留侧栏和底部播放栏；无独立窗口、无拖动、无置顶。
- 唯一入口改为模块管理页插件配置的“打开听歌统计”；`MainPlugin.openStats` 只设置 `StatsHostState.visible`。
- 打包 SaltUI **3.0.0-beta02**（宿主 Salt UI 3.0.0-SNAPSHOT / CMP 1.12.1）；使用 `SaltTheme` 和 SaltUI `verticalScroll`，内嵌页可滚轮滚动。
- 控制行 `FlowRow` 改为垂直居中，修复图一“每天/每周”和“2026年”不横向对齐。

隔离配置截图：`build/screenshots/embed_proto.png`、`embed_scrolled.png`（不提交）。截图确认页面在宿主内容区、pill 消失、播放栏未遮挡、滚动后图表和听歌小结可见。

**未完成：** 关闭/返回按钮当前在内容区左上角（X），位置/图标待用户确认；卡片、按钮、文本和热力图仍主要是 Material3/自绘，SaltUI 目前只承担主题和滚动；固定 dp 的响应式替换尚未完成；配置页入口尚未由用户点击验证。

## 0.1.2 UI 修订

2026-10-18，针对用户实际运行截图和源码定位。保持 preview/ 基准，不改数据统计口径。

| 问题 | 修订 |
| --- | --- |
| 热力图提示框跑到页面顶部 | Popup 使用锚点窗口坐标加局部指针坐标，靠边翻转并限制在窗口内 |
| 滚动后提示框残留 | Swing viewport 变化通知 Compose 清掉旧悬停状态 |
| 空数据纵轴连续显示“1” | 按刻度步长保留必要小数，空数据用 0–4；空态不画零值曲线和平均线 |
| 图表首尾文字偏离数据点 | 两端留空间，末标签按真实数据中心绘制；命中范围限制在绘图区 |
| 分组控件过大 | 对这类桌面小按钮关闭 Material3 48dp 默认占位，保持基准 29dp 按钮高度 |
| 图标没有提示或名称 | 图表类型/主题按钮增加悬停提示和无障碍名称 |
| 日周切换缓存错误 | 周数据记忆键包含 weekly，切换时清理旧悬停 |
| 周图画出跨年方格 | 两种模式均只绘制本年的日期，零时长周也能显示选择框；周累计排除未来日期 |
| 热力图高 DPI 尺寸混用 | 标签空间、间距、圆角与可用宽度在同一物理像素坐标中计算 |
| 日期标签缺年份 | 选日和自定义范围都显示完整日期；23 点小时提示终点为 24:00 |
| 返回概览丢失年份/模式 | 状态提升到页面容器，切页保留 |
| 固定页面高度、缩放后的空白/截断 | 改为内容实际测量高度，转换成 Swing 逻辑尺寸；不再写死 1300dp/排行估算高度 |
| 完整日期容易挤压控件 | 区块标题在较窄宽度上下排列，操作组允许换行 |

检查：构建、`py -3.12 tests/run-data-tests.py ui` 和包结构检查集中执行一轮。几何回归覆盖提示框锚点/边缘/多 DPI、刻度精度、周汇总与午夜标签。**这些检查不等于宿主渲染或鼠标验收。**

结果：30 个 Kotlin 文件编译通过，4 组 UI 几何回归通过，包结构检查通过（106 项）；0.1.2 包为 14,661,972 字节。检查发现两个文件末尾多余空行，已清理，不重复运行构建和通过的回归。

本轮未启动或安装 SPW，没有新的运行截图。新版需用户实际核对提示框位置、滚动高度、日周切换、图表刻度、按钮大小及浅深主题。整个 UI 尚不能标为完成验收；已有独立窗口与版本绑定 Hook 等限制继续保留。
