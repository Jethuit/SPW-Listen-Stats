# 0.1.23 双日历卡片与下拉菜单收窄

2026-10-19。按用户最新要求覆盖 0.1.22 的“双月联动、依次点击起止日期”方案；仍保留内嵌页、MiSans、浅深主题和每页 25 首。

## 一、日期弹窗：两个独立日历卡片

- 左右两张等宽卡片：**起始日期**、**结束日期**；使用 `subtle` 底色 + 1dp 边框 + 12dp 圆角，白色对话框背景，无重阴影。
- 每张卡片独立维护 `YearMonth`：
  - 独立年份 SelectBox、月份 SelectBox、上/下月箭头。
  - 左侧切换年月不影响右侧，右侧也不影响左侧。
  - 切换年月只浏览，不改变已选日期。
  - 点击左卡日期只改开始日期，点击右卡日期只改结束日期。
- 打开时左卡定位 `initialStart` 所在月，右卡定位 `initialEnd` 所在月，各自高亮已选日期。
- 不自动交换/不自动修改另一侧；开始晚于结束时显示“起始日期不能晚于结束日期”，并禁用“确定”。
- 底部合法时显示：`2026年9月20日 至 2026年10月19日 · 已选 30 天`；天数含首尾；同一天为 1 天；非法时不显示负数。
- 取消/Esc 不应用；确定才更新。
- 日期网格按 `min(cardWidth/7, 34dp)` 计算单元，接近正方形并居中；卡片变宽不会把日期拉成宽条。
- 响应式：内容宽度 ≥620dp 且字体缩放 ≤1.15 时双卡并排；否则上下排列，起始在前、结束在后，字号不缩小。
- 键盘：对话框根/遮罩可聚焦，Esc 取消、Enter 在范围合法时确定。

**截图：** `build/screenshots/cards_final.png`（双卡、独立年月、各自 18 日高亮、已选 1 天、确定可用）。

## 二、下拉菜单

`SelectBox` 改为自行绘制 Popup 菜单，不再使用 Material3 `DropdownMenu` 的默认最小宽高和默认 padding。

- 外框宽度：按最长选项文本 + 20dp 文字留白计算，最小 **144dp**；不再继承触发按钮的长日期宽度。
- 菜单内部 **6dp 四周留白** 在选项背景节点之外。
- 选项背景在留白以内，小圆角；选中 `controlBackground`、悬停 `hover`；左右不接触菜单外框。
- 文字在选项背景内再留 **10dp** 横向内边距。
- 行高 34dp；无 Material 默认最小高度叠加。
- 年份菜单选项很多，增加 320dp 最大高度和滚动，避免把菜单撑到窗口顶部；短日期预设菜单自然保持紧凑。
- 菜单位置使用捕获的 anchor + `PopupPositionProvider`，空间不足时翻到上方并夹在窗口内。

## 四、封面性能

沿用 0.1.22 的分段日志与优化，无新增结论：

- 3 并发基线：wait 0–389ms、api 3–199ms、decode 5–151ms、ui 191–627ms。
- 4 并发实测：wait 0–355ms、api 3–244ms、decode 21–160ms、ui 约 300–562ms。
- 主要耗时仍是排队；API/解码多数很快。未测滚动 FPS、内存、缓存命中返回、显式可见项优先级。
