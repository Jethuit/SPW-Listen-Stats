# v0.1.3 开发版修复

日期：2026-10-20。基于用户审查的 `main` / `139e1b082929568c4068281f004b4a897b78230c`，已快进同步其 README 修改。本轮不上传 GitHub，不改变 v0.1.2 Release，也不操作真实播放器数据。

## 四项修复

以下数据完整性修复已纳入 dev.1，dev.2 继续包含。

1. **生命周期片段重复累计**：允许同曲、近似相同播放起点且实际收听区间不重叠的片段对应同一宿主记录。将片段合并为一次播放，再与宿主快照比较完整程度，保留所有片段 ID 别名，使旧导出重导入仍可去重。
2. **旧位置配新歌曲**：在回调到达时捕获播放状态修订号、位置序号及此前已观察到的歌曲身份；后台查询完成后再次校验。过期队列、跨越状态变化、查询超时或前后歌曲身份不一致时丢弃该采样。首次身份观察只建立基线。
3. **元数据被较长的未知记录覆盖**：收听区间选择和歌曲信息合并分开处理。保留已知标题、歌手、专辑、专辑艺术家和正数曲长；聚合时还可从同一来源、同一歌曲的其他事件补齐信息，避免未知记录覆盖排行元数据。
4. **来源身份损坏破坏去重**：新增冗余身份文件和实时文件中的来源标记；主文件损坏时先恢复冗余身份，再尝试本地实时记录的标记或唯一宿主别名前缀。对于已被旧版本重新生成的身份，仅对能用歌曲与时间重新匹配的宿主记录迁移别名，并保留旧别名连接历史备份。运行中的旧会话副本回写不会把已迁移的别名覆盖回去。

新增的可选实时文件字段保持 `version: 2`，旧版记录仍可读取。来源身份恢复只参考本机实时存储，不从导入的其他曲库备份猜测本机身份。显式别名已连接本地宿主记录时，较长旧备份仍归入当前本地曲库。

## 能力边界

- 宿主 API 没有原子的“歌曲＋位置”快照。修复采用前后身份与回调序号校验，无法确认归属的采样会丢弃，因此启用或切歌边界可能少记一小段时间；不补猜这段时长。
- 宿主记录关联仍是近似起点匹配。多片段共享记录时额外要求起点差不超过 **250ms** 且实际区间不重叠，以避免将短间隔重播折叠。超出可靠条件的历史片段不强行归并。
- 主身份、冗余文件和本地实时记录都无法提供可恢复身份时，才生成新 UUID；未验证的历史关联不自动迁移。
- 这次没有对真实数据库或旧备份做批量改写；已发生且缺少可靠归属证据的旧采样不自动删除。

## dev.3：歌曲 / 歌手 / 专辑排行

- 搜索框左侧复用现有分组控件，切换歌曲、歌手、专辑榜，标题、搜索提示、表头及数量单位同步变化；窄屏将按钮行放到标题下方。极窄窗口隐藏表格次要列、优先显示名称和次数，搜索提示保持单行。保留每页 25 项、全榜排名搜索和翻页，切换类型回到第一页，模式偏好保存到本机。
- 按用户确认，以单曲有效播放次数相加。合作歌曲的次数分别计入每位歌手，同一条歌手标签重复出现不会重复加次数；按 `/`、`;`、`；` 拆分，不按 `&` 或逗号拆乐队名称，保留 `AC/DC` 完整名称。SPW 只提供歌手展示字符串，其他包含斜杠的完整艺名或没有分隔符的合作标签仍可能无法正确识别。
- 专辑按标题和专辑艺术家归组；无专辑艺术家时回退到歌曲的歌手标签，缺专辑标签时保留独立条目。缺少专辑艺术家的合辑可能分成多个条目，不猜测归属。同名不同艺术家的专辑不会合并。
- 歌手使用文字占位图，不用歌曲封面冒充歌手头像；专辑复用该组最高播放歌曲的封面来源。新榜单在展示层汇总，不改写收听数据或备份格式。
- 验证入口：`py -3.12 tests/run-data-tests.py ranking`、`py -3.12 tests/render-back-button.py --ranking`；合成数据覆盖合作计次、同名专辑、未知标签、长整数累计和搜索分页。
- 验证结果：39 文件构建成功，新增排行回归 **6/6**、原有 UI 回归 **7/7** 通过。已渲染三种榜单、两种宽度、两种主题的 12 张原生预览，修复检查中发现的极窄窗口名称列和表头显示问题；实际 SPW 显示及点击仍由用户验收。包结构检查通过，157 项、17,231,594 字节，无新增权限。

## dev.4：歌手封面与原版列表尺寸

- 歌手使用其计次最多的专辑封面：先将该歌手参与的歌曲按专辑归组、求有效播放次数合计，选中最高专辑，再使用该专辑内最高计次歌曲的封面来源。并非直接拿歌手最高计次单曲的专辑；合作歌曲仍分别计入参与歌手。同名不同专辑艺术家的专辑继续分开，缺专辑标签时回退到该歌手最高计次歌曲，封面读取失败时保留默认图。
- 本次截图测得封面约 60×60px，结合 275px 侧栏对应 220dp 的既有宿主布局，按 125% 缩放换算为 48×48dp；封面到文字约 15px（12dp），行距约 82px（约 66dp）。三种排行统一由 44dp 封面改为 48dp，圆角改为 4dp，内容行 65dp＋现有 1dp 分隔线；标题调整为 14sp/20sp，副标题 12sp/16sp。实际字体和像素取整仍由宿主缩放决定，不宣称整个列表逐像素一致。
- 新增回归区分“最高单曲”与“最高专辑合计”，包含合作归属、同名专辑区分及缺失专辑回退。原生预览改为模拟 API 返回合成封面，检查三种榜单、浅深主题、窄宽窗口中的实际图像大小与行距，不访问真实曲库。
- 验证结果：39 文件构建成功，排行回归 **7/7** 通过；12 张原生预览的外部封面边界均为 60×60px（包含圆角边框），相邻行约 82–83px，符合本次 125% 缩放尺寸。包结构检查通过（157 项、17,233,394 字节）。未启动真实 SPW，实际封面读取和观感由用户安装核对。
