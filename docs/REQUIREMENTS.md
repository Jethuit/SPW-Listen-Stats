# SPW-Listen Stats：正式模组需求

更新时间：2026-10-22。本文记录用户已确认的最终状态；早期截图与已撤回的设计不覆盖当前 `preview/`。后续新增需求直接更新本文；实现与构建说明见 `plugin/README.md`。

## 目标与实现约束

为 Salt Player for Windows 制作“听歌统计”模组。正式前端完全按照当前示例的布局、文案、交互、图标与主题实现，优先原生 Kotlin / Compose / Salt UI。需要实际可安装的 `.spmod`，而不只是网页或 UI 演示。

用户已提供本机 SPW 安装目录供研究。统计页通过宿主 Hook 嵌入内容区，入口与宿主版本绑定。无法按示例实现的部分须明确告知用户，并在有重大替代方案时询问，不静默改设计。

2026-10-22：适配 SPW 1.19.1 更新造成的页面与标题栏入口失效，保留 1.19.0 的接入位置；不改变已确认前端与统计口径。页面 Hook 失败时明确提示记录器与页面的不同状态，不能提示用户改从同样不可用的配置入口打开。真实窗口、AOT 及多插件兼容性须与静态签名／宿主解析器检查区分说明。

视觉基准是 `preview/index.html`、`preview/styles.css`、`preview/app.js`；与本文后续确认的需求有差异时以本文为准。

## 统计与数据

- 记录真实听歌时长，并按本地自然日、小时保存；跨日或跨小时的时长需要正确拆分。
- 时长文字按分钟四舍五入：对最终合计时长一次舍入，余数不足 30 秒舍去，满 30 秒进位；不是每 30 秒计一分钟，也不逐片段舍入后再相加。提示、总时长及统计卡片共用，跨 60 分钟进位到小时；原始数据、图形高度、热力颜色档位与有效播放次数不受影响。
- 播放次数按每首歌曲独立累计；2026-10-20 用户新增歌手、专辑榜，按所含歌曲的有效播放次数求和，合作歌曲分别计入每位歌手。不展示跨榜单的全局总播放次数。
- 有效播放口径：同一次播放实际听满该歌曲时长的 50% 计一次。暂停和拖动跳过的进度不计入实际收听时长。
- 同名歌曲依歌曲身份分开，不能仅用歌名归并；曲库 ID 重建、跨设备等身份与兼容性限制见 `plugin/README.md`。
- 原生模组需要持久化统计，重启不丢失。预览目前只在内存中运行，刷新会恢复示例。
- 保留本地导入、导出入口。正式备份应有版本、校验及导入失败处理，不能直接把预览 JSON 当正式格式。
- 预览的日期、数字、歌曲和封面全是演示数据，正式模式不可默认显示为用户的真实记录；也不能凭已有曲库推算过去的收听历史。

2026-10-18 用户确认：同一遍播放按实际收听时间累计，拖回重听可累计，每遍最多计一次；暂停继续仍属同一遍，自动循环或重新从头播放开启下一遍。插件中途启用只记录观察到的收听片段；未知时长先记录时间，不猜测 50% 次数。

用户确认备份导入必须与本机合并并去重。新版使用会话身份；旧版 v1 无会话身份，用户同意兼容并明确提示可能少计，按小时和每首次数取较大值保守合并。不能把旧版汇总的保守合并宣称为精确去重。

## 页面结构与外观

- 顶部标题固定“听歌统计”，位于返回键右侧，与原生桌面标题栏一致：56dp 栏高、返回按钮后间隔 8dp、24sp 常规中等字重。右侧为“…”按钮；标题不随正文滚动，正文不再重复放标题。排行页也不改成“听歌排行”，不放副标题。
- “听歌概览 / 听歌排行”分为独立页面，导航字号 15px；切页保留当前筛选与数据。
- 两项导航继续顶部横排，按钮之间无空隙，距标题栏底部 12dp，按钮高 36dp、常规字重，选中与悬停均不填充灰色底，按钮背景透明。删除左侧竖条，改为按钮底部 2dp 高的蓝色横条，左右边缘与上方“图标＋间隔＋文字”内容对齐，不包含按钮左右内边距；切换时横条在两项之间左右滑动，300ms，快速反向切换不排队。选中状态通过文字和底部蓝条表达，导航项取消控件自带的悬停／按压灰色反馈层，鼠标经过只可改变文字色；保留点击、键盘操作和无障碍选中状态。
- 删除进入前的独立加载页面及“正在读取”文字。首次读取期间保留返回键、标题、两项导航，正文显示静态中性占位；可以返回或切换排行。后台读取就绪后直接替换占位，不重播整页入场、不把未读取数据显示为 0；只有得到快照后才开放备份操作。
- 统计整页采用 SPW 桌面原生转场参数：新页从下方 150 个布局像素滑入，不额外淡入；原宿主页同时原位淡出。明确返回时统计页向下 150 像素滑出并淡出，原宿主页原位淡入。直接切到其他页面时，统计页原位淡出，新页在其上方进入并覆盖，不能先播放向下退出，也不等待旧页退完才显示新页。位移与透明度均用刚度 500、阻尼比 1 的弹簧，实际完成后清理旧统计页，不固定为 300ms；页背景随外壳一起移动。统计页仍通过现有内容层接入，不宣称成为宿主 NavDisplay 场景。
- 概览/排行只让主体左右滑动淡入淡出，标题和导航固定。排行的歌曲／歌手／专辑切换与翻页也采用左右滑动淡入淡出，方向随目标位置变化；切出内容保留原快照，正常数据刷新不重播。内部页面、排行主体与备份菜单显隐仍为 **300ms**（搜索框按下述原生节奏），配置页提供“页面动画”开关，默认开启；关闭后直接显示或切换，菜单也不做淡入淡出。重复选择不重播，快速反向切换不排队；短末页定位等待内部切页完成。
- 转场期间保留统计页，动画实际完成后才移除；原宿主页仅在进入统计／明确返回时参与视觉淡出淡入，统计显示期间宿主正文不接收鼠标或键盘操作。退出中的统计控件不接受输入，菜单和日期弹窗立即收起。返回只关闭统计，不额外弹出宿主历史；点击宿主侧栏、替换或前进时，让原请求完整通过其他插件离开保护，被接受后目标页在统计页上层进入，统计页原位淡出。宿主底层更早的页面立即退出绘制，不能把“专辑 → 统计 → 歌曲”画成先恢复专辑。离开请求若被延后或取消，统计页保持；确认重放并被接受后再切换。连续导航沿用宿主的最新目标；重新打开统计只反向取消视觉退出，不回滚宿主已经接受的导航。禁用、组件卸载与旧回调不能触发额外跳转。关闭页面动画时立即交接。
- 右上角导入、导出合并为一个 Salt UI 无描边“…”按钮。展开菜单使用与年份下拉菜单一致的主题背景、9dp 圆角、1dp 细描边及 4dp 阴影。菜单宽度仅容纳两个字与 Salt UI 必要内边距，不沿用 180dp 最小宽度；仅显示“导入 / 导出”文字，无图标。菜单靠按钮右侧对齐并避让窗口边缘，操作后关闭，沿用现有备份流程。
- 2026-10-22：分页当前页与年份、日期范围等共用下拉菜单的当前项不再使用蓝色文字，改为主题普通文字色；保留原选中底色、悬停反馈及行为。热力格、图表等数据强调色不在本次调整范围。
- 2026-10-20 最新确认：删除插件深浅主题切换功能及按钮，始终跟随 SPW 宿主深浅主题。宿主明确选择的浅／深优先于操作系统；宿主跟随系统时才读取系统深浅色。旧插件主题偏好和启动主题覆盖不再生效，不提供手动模式。
- 以当前留白、细边框、蓝色强调色为准；浅深主题均需适配。原生字体渲染差异可以说明，不能据此擅自改变布局。
- 适配椒盐经典、亚克力、云母、云母 Alt；支持材质的嵌入入口继承宿主窗口背景，材质入口不可用时保留安全实色底。打开统计时不能透出底层歌曲列表，也不应清空原页面状态；真实 DWM 观感需实机验收。
- 材质包装不能与其他插件争用 AppNavigation 外层替换位置；应在其内部布局保留原调用参数，其他插件仍调用原导航时继续生效。诊断日志区分 Hook 注册和材质包装实际组合状态。
- 统计与歌词插件直接互切同样按新页覆盖旧页处理，统计原位淡出；没有原生路由转场的工具页由内容层提供 150 像素的弹簧滑入，不先将统计向下退走。内容层要覆盖其他插件在 AppNavigation 外层绘制的页面，避免更早的宿主页或旧工具页叠加。同页导航请求不延后回放，避免关闭刚打开的目标插件；快速返回统计仍经过对方离开确认，视觉退出完成不取消较新的待确认请求。
- 从标题栏或配置打开统计时，先通过宿主导航通知其他工具页离开，再显示统计。歌词页若有未保存内容，由其原有确认流程决定是否离开；取消时保持歌词页，确认后再显示统计。重复请求、其他导航、关闭及禁用必须使旧请求失效，不叠加两个透明页面，也不向宿主历史插入统计页面。
- 椒盐经典列表悬停按原版截图适配：浅色 `#E8E8E8`，深色 `#363637`，用于三种排行；图表悬停标记及仅一个数据点时的圆点使用实心强调色，取代此前空心透明方案。
- 四种材质、浅深主题的概览与排行都删除灰色分隔线，包括标签栏下横线、排行表头／记录间／列表末尾线、概览页脚线及累计统计／听歌小结内部竖线。导航保留当前按钮底部蓝色滑动横条，热力格及图表继续使用蓝色强调色。保持现有间距，卡片外框及图表坐标网格继续使用原样式。歌曲、歌手、专辑三种排行共用此结构。

## 听歌概览

### 顶部累计统计

一个圆角边框内四列等宽，内容居中、列间不画分隔线：累计听歌时长、听歌天数、最长连续、当前连续。大数字、小单位。当前连续的预览逻辑：当天还没有听歌时，允许从昨天延续计算。

### 听歌热力图

- 标题“听歌热力图”，右侧“每天 / 每周”纯文字分组按钮及年份下拉，年份显示“2026年”这样的格式。
- 两个模式共用日历网格：从周一开始，七行；左侧保留“一、三、五、日”，月份在上方。
- 参考用户视频：格子从左往右逐列淡入并轻微放大，整段约 650ms；首次显示、每天／每周和年份范围切换时播放，普通数据刷新与选中日期不重播。月份与星期标签保持稳定，快速切换只展示最新目标；页面动画关闭后直接显示全部格子。650ms 用于热力图，内部页面与导航动画仍为 300ms，整页使用原生弹簧，搜索沿用原生节奏。
- 平年 365 个、闰年 366 个可见方格，年初、年末跨出该年的槽位都留空。每天与每周的数量、日期位置和大小一致。
- 方格圆角 **6px**；每日选中外框对应为 8px。保留悬停、焦点和选择效果。
- 每日颜色按最近 12 个月（含今天）的非零日时长计算 25%／50%／75% 四分位阈值，映射四档蓝色；零时长单独为灰色，未来日期不参与。删除“每天听多久算多（小时）”设置及其读取链路，旧配置值不再生效，不主动改写用户配置。
- 阈值采用有序样本位置 `(n-1) × 分位数` 线性插值；等于分界时归较浅档，相同时长保持同色，不强求每档数量相等。只有一个样本或全部相等时显示第一档；无最近一年样本时，旧历史的非零时长也显示第一档。阈值随最近一年分布变化，查看旧年份仍使用同一最近一年基准；不改变原始时长、计次及图表坐标。
- 每周一列代表周一至周日的汇总，用最多七个自下而上的色块表示高度；高度仍相对所查看范围的单周峰值。颜色改为最近 12 个月中非零自然周时长的独立四分位阈值，跨窗口边界周只采窗口内记录，当前周只采今天及以前。网格跨年周仍仅显示所选年份内的日期与时长。分档思路参考 [GitHub 公开的贡献等级定义](https://docs.github.com/en/graphql/reference/users#contributionlevel)，不宣称使用其内部具体实现。
- 每天／每周模式切换先清空热力图选择，不把选中日转换成选中周；重复点击当前模式不清空。由热力图联动的单日或周范围恢复今天，手动选择的日期范围保留；实际点击某周后再联动该周分布。清空选择和恢复范围写入偏好，重开不恢复旧的热力图框选。
- 每周选中或悬停时，每个有效日期方格分别描边，取代整列大外框；完整周显示七个独立框，年初、年末跨出显示范围的日期不画框。
- 不显示热力图下方的说明、点击提示、缩放说明和“少—多”颜色图例。
- 每天提示：第一行“2026年9月14日”，第二行“听歌时长 2小时30分钟”。每周提示：第一行“2026年9月14日起的一周”，第二行“听歌时长 12小时18分钟”。全部左对齐，数值紧跟标签。
- 点击某天，联动下方该天的小时分布；点击某周，显示该周每天的时长，时长分布的日期框文字显示“自定义”；打开自定义日期弹窗时仍带入该周的实际起止日期。仍保留鼠标与键盘操作。

### 时长分布

- 标题“时长分布”，下方保留所选范围的听歌总时长说明。
- 支持柱状、折线、平滑曲线。三个切换按钮仅保留 Google 图标及无障碍名称；首次使用默认柱状图，柱状／折线／平滑曲线的最后选择保存在本机配置，关闭重开及重启后恢复。曲线保持单调插值，不超出相邻数据的极值。
- 日期范围首次使用默认今天；已有用户仍恢复上次选择，不强制覆盖。取消热力图框选或清空其联动范围时也回到今天。日期范围包含近 7 天、近 30 天、本月、今天、热力图选中日期、自定义日期；日期框不带日历图标，保留下拉箭头。选日显示完整日期，热力图选周显示“自定义”，手动确认的自定义范围显示实际起止日期。
- 日期与粒度智能联动：单日固定显示 24 个小时区间；2～13 天固定按日；14 天及以上才显示“按日 / 按周”下拉。短范围自动选择不能覆盖长范围的粒度偏好。
- 周汇总沿用预览：从当前日期范围起点起，每七天一组，末组可不足七天；不要默默改成自然周。
- 所有横轴标签都居中对齐到对应柱子或数据点，首尾预留空间，窄屏减少标签。小时标签表示区间起点：00:00 对应 00:00–01:00，23:00 对应 23:00–24:00。小时折线、平滑曲线及其填充沿首末端点值平直延伸至绘图区左右边界，补齐两端半个区间；数据点、标签与悬停标记仍保持区间中心坐标。稀疏标签之间的距离与真实时间跨度成比例。
- 纵轴按数据选择小时或分钟，刻度避免重复或错位。缩放后鼠标位置要正确转换，提示、柱子、曲线、标记使用同一坐标。
- 按日与按周有平均时长横虚线，平均值标在左侧纵轴，包含零收听时段；相邻普通刻度让位避免重叠。**单日按小时隐藏平均线**。
- 不显示图下重复日期范围、“悬停查看详情”，也不保留“查看图表数据”及其表格。

### 听歌小结

保留“听歌小结”标题，标题上方无横向分隔线。下方与顶部相同：一条圆角边框，三列等宽、居中、无竖线分隔，每列仅两行：

| 列 | 第一行 | 第二行 |
| --- | --- | --- |
| 第一列 | 大数字、小单位的单日最高时长 | 听得最多 · 实际日期 |
| 第二列 | 大数字、小单位的平均收听时长 | 每日平均收听 |
| 第三列 | 常听小时区间，如 21:00 — 22:00 | 最常听歌时段 |

“每日平均收听”仍按有收听记录的日期计算；这与时长分布包含零值的范围平均线不同。常听时段按全部记录的小时累计计算。空数据显示真实空状态，不使用示例数填充。窄屏在同一外框内纵向排列。

概览到听歌小结结束，不再显示底部的连接状态与收听口径说明行。

## 听歌排行

- 单独页面，顶部主标题仍为“听歌统计”，内容标题随模式显示“歌曲播放次数 / 艺术家播放次数 / 专辑播放次数”。歌曲模式内容标题保留“歌曲”，不随表头改为“标题”。
- 排行右侧采用原生工具栏风格：A–Z 图标打开原生样式的“标题／艺术家／专辑”下拉，依次对应歌曲／歌手／专辑排行：菜单居中对齐图标，宽度至少 112dp、32dp 行高、4dp 外内边距，左侧保留勾号列；当前项用普通文字色及勾号，悬停使用内缩圆角灰底，不用整行固定选中灰底；菜单跟随 Salt UI 主题背景、细描边和阴影。搜索图标与“胶囊输入框＋圆形关闭按钮”作为整体切换，按原生 ScreenSearchBar 使用 AnimatedContent：旧内容淡出 90ms，新内容延迟 90ms 后以 300ms 淡入并从 0.92 倍放大；容器宽度随原生 SizeTransform 变化，右对齐工具栏向左让位。搜索框沿用宿主的单物理像素主题描边与次级底色，关闭按钮使用原生 Salt UI PillButton。搜索显隐沿用页面动画开关，关闭动画后立即切换；自动聚焦，关闭或 Esc 清空筛选并收起。可用时直接读取宿主 A–Z、搜索图标资源，缺失时使用本地图标回退；不复制宿主资源。仍按播放次数排序，不加入排序或批量勾选功能。歌手和专辑汇总有效播放次数，合作歌曲分别计入每位歌手；切换回第一页，保留搜索文字和榜单模式偏好。
- 2026-10-20 后续确认：歌手榜以该歌手播放次数最高的专辑封面代替头像，按专辑内歌曲的有效播放次数合计选择。三榜列表参考原版适配：封面 48dp（截图 125% 下约 60px）、行距约 66dp，图文间距 12dp。
- 歌曲模式表格列为：排名、标题、专辑、播放次数；艺术家模式前两列表头为“排名、艺术家”，专辑模式为“排名、专辑”。**排名表头和序号均居中**；次数靠右。
- 歌名左侧方形专辑封面，歌手在歌名下方。同专辑可共用封面，缺失或读取失败显示默认图。
- 默认固定按每首播放次数从高到低排列。不再提供歌名、歌手排序下拉；次数相同时按歌名中文次序，同名同次数保持原顺序。
- 支持歌名、歌手搜索，覆盖全体歌曲，保留榜单原排名；搜索和导入后回到第一页。
- **每页默认 25 条**，可在配置页自行输入正整数，无效输入回退 25 条，对歌曲、歌手、专辑三个排行共同生效。更改后回到第一页；重新打开统计页或约 5 秒自动刷新时读取新设置。列表底部提供页码与上一页／下一页，显示总数和当前范围，只渲染当前页；不足一页隐藏翻页。翻页后根据原操作位置保持顶部或底部阅读位置，短末页不因滚动范围为零触发错误跳转。
- 底部一行说明：“每首歌独立累计 · 实际听满歌曲时长的 50% 计一次 · 不受概览页年份与日期筛选影响”。
- 三种排行都是累计数据，不随概览的年份、日期筛选变化。歌手和专辑榜按本次新增口径汇总，不额外显示跨榜单总次数。
