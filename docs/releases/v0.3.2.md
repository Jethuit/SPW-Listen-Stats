# v0.3.2

发布日期：2026-10-26

## 变化

- 新增排行指标菜单，可在播放次数和累计实际收听时长之间切换。
- 歌曲、艺术家和专辑排行均支持收听时长排序、搜索与分页；时长按已合并事件的实际收听片段累计，暂停和拖动跳过的时间不计入。
- 未达到 50% 播放次数门槛但存在实际收听片段的歌曲，也会出现在收听时长排行中。
- 宿主 `Listen` 表改为启用会话内的只读缓存：无变化时复用快照，连续追加时读取新增 `rowid`，发现更新、删除、重建或并发变化时安全回退全量读取。
- 停用插件时释放宿主数据库连接，并补充数据库增量读取与时长排行回归测试。

## 构建与兼容性

基于 **SPW 1.19.2** 构建。包结构、Manifest 版本和排行／数据库回归检查已通过；真实窗口、AOT 模式、多插件共存、DWM 材质和跨版本宿主兼容性仍需实机核对。宿主内部结构或 API 变化仍可能需要后续适配。
