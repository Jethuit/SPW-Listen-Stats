# SPW热力图&排行 v0.1.0（预发布）

查看听歌热力图、时长分布与歌曲排行，支持备份导入、导出。

**推荐使用“椒盐经典”主题样式，获得最佳体验。**

**安装：** 下载 `SPW-Heatmap-Ranking-v0.1.0.spmod`，在 SPW 中本地导入并按提示授权启用，然后进入模组配置点击“打开听歌统计”。

适用于 **SPW 1.19.0**。兼容性与已知限制见 [README](https://github.com/Jethuit/SPW-Listen-Stats/blob/codex/listening-stats/README.md#数据与兼容性)。
