# 听歌统计 v0.1.0（预发布）

首个公开预发布版，面向 **Salt Player for Windows 1.19.0**。可以在播放器内查看听歌概览与歌曲排行，统计保存在本机。

## 功能

- 听歌时长、听歌天数、最长连续与当前连续天数。
- 每天／每周听歌热力图，支持年份与近一年视图；时长分布支持柱状、折线和平滑曲线，以及日期范围筛选。
- 每首歌曲独立累计有效播放次数，口径为同一遍实际收听达到歌曲时长的 50%；排行支持歌名／歌手搜索，每页 25 首。
- 跟随 SPW、浅色、深色三种主题；本地备份导入、导出与合并去重。

本版包含开发阶段的封面请求取消、共享加载、失败重试及日期弹窗键盘／滚动修复。

## 安装与打开

1. 下载附件 `plugin-com.jethuit.spw.listenstats-0.1.0.spmod`。
2. 在 SPW 的创意工坊／模组管理中使用本地导入，选择该文件。
3. 按宿主提示授权读取曲库（`library-read`）和界面 Hook（`class-transform`），然后启用模组。
4. 在模组配置中点击 **“打开听歌统计”**。

如果安装后没有立即显示入口，可重启播放器后再进入模组配置。无需另装 Java 或 Kotlin。

附件 `SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。Windows 可用 `Get-FileHash -Algorithm SHA256 <安装包路径>` 查看本地值并对照。

## 已知限制

- 兼容性开发与运行基准为 SPW 1.19.0，界面入口依赖宿主内部 Hook；其他版本尚未验证。
- 可读取的历史受宿主实际保留记录限制。宿主旧历史缺少暂停等精细片段，按小时分配属于近似；新记录与宿主记录的匹配也仍有启发式边界。
- 真实播放、暂停、拖动、循环、宿主落库去重，以及最新日期弹窗的键盘和缩放场景仍需继续在正常宿主中验收。离线回归通过不代表这些场景已全部验证。
- 封面接口只提供可读取的内嵌封面；缺失时显示占位图，暂时失败按 30 秒冷却重试。
- 旧版 v1 汇总备份采用保守合并，可能少计；曲库删除重建或跨设备后不保证歌曲 ID 保持一致。
- Acrylic／Mica 等背景暂回退为经典配色；入口位于模组配置中，当前没有顶部标题栏入口。

## 验证范围

发布准备时通过 18 个数据回归用例、6 组 UI 计算回归、8 组封面并发／取消回归，以及安装包结构和许可证检查。均为隔离检查；真实宿主场景的待验收范围见上文。
