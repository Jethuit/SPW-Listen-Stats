## 更新日志

v0.2.0 正式版 · 2026/10/22

### 界面与动画

1. 调整“听歌概览／听歌排行”导航：两个按钮紧贴排列，去掉灰色选中和悬停底色，底部全宽蓝条随切换滑动。
2. 将“听歌统计”标题移到返回键右侧，保持标题和导航固定；删除独立加载页，首次读取数据时在正文显示静态占位。
3. 新增进入时向上淡入、退出时向下淡出的动画，以及概览／排行、排行类型和翻页的切换动画。页面和导航动画为 300ms，快速反向切换不排队。
4. 排行工具栏改为原生样式的“标题／专辑／艺术家”菜单，分别打开歌曲、专辑、歌手排行；当前项显示勾号，支持展开式搜索与原生节奏的搜索框动画。
5. 导入、导出合并到右上角“…”菜单，使用紧凑文字选项。
6. 新增“排行每页数量”和“页面动画”配置，可自行输入每页条数或关闭界面动画。

### 热力图与时长分布

1. 热力图根据最近 12 个月的非零听歌时长自动计算四分位颜色阈值，每日、每周分别计算；零时长保持灰色，移除“每天听多久算多”设置。
2. 热力图新增约 650ms 的从左向右逐列显现动画；普通数据刷新和选中日期不会重复播放。
3. 修复每日切换到每周时自动选中原日期所在周的问题。切换模式先取消框选，由热力图联动的范围恢复“今天”，手动日期范围保留。
4. 每周选择改为七个日期方格分别描边，跨年周只描绘显示范围内的方格。点击某周后显示该周时长分布，日期框显示“自定义”。
5. 时长分布首次默认“今天＋柱状图”；已有用户仍恢复保存的日期范围和图表类型。
6. 修复自定义日期范围显示、短末页翻页定位等界面问题，去掉概览底部的状态说明行。

### 统计、性能与备份

1. 改进播放采样建立、单曲循环边界判断及暂停或拖动后的宿主记录匹配，保留跨曲目的异步隔离保护。
2. 修复旧版备份合并时曲目信息的保留顺序问题。
3. 减少一次刷新中的重复全量聚合，缓存未变化的导入备份以减少重复读取；移除每秒启动注册表查询进程的主题轮询。
4. 将备份导入、导出处理移到后台，补充空封面缓存，减少重复读取。

### 兼容性与诊断

1. 调整材质接入位置和页面切换流程，改善与占用主窗口导航的歌词插件共存时的背景失效、页面叠加问题，并保留其他插件的离开确认流程。
2. 退出期间收起弹层并屏蔽统计控件，动画完成后再执行宿主跳转；重复操作、重新打开和禁用会取消过期跳转。
3. 补充诊断日志内容及实际输出路径提示，修正 Manifest 按 UTF-8 字节折行的打包问题。

适用于 **SPW 1.19.0**。下载 `SPW-Stats-v0.2.0.spmod`，在 SPW 模组管理中本地导入并启用。

本次更新保留原有统计与备份口径，建议更新前导出一份本地备份。跨设备或重建曲库后的歌曲对应限制仍然存在。部分非 ASCII 安装路径下的宿主 Agent 安装失败尚未解决，不属于本次 Manifest 修复的范围。

验证包含合成数据回归、模拟导航及浅深主题离屏检查；不同 SPW／歌词插件构建及 Windows 材质效果仍以实际运行情况为准。

使用说明见 [README](https://github.com/Jethuit/SPW-Listen-Stats#readme)。
