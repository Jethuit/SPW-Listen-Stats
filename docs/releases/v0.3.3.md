# v0.3.3

发布日期：2026-10-28

## 变化

- 将排行索引和搜索计算移到后台，减少大数据量下的界面卡顿；搜索增加防抖，刷新时保留上一份排行结果。
- 宿主歌曲元数据只读取历史实际引用的歌曲，减少无关曲库读取。
- 修复排行刷新时的闪烁。
- 修复导入／导出备份时 Swing 文件对话框阻塞 Compose 调度器导致的崩溃。
- 修复导入／导出文件对话框的同步等待链，改为可取消的 EDT 异步调度，避免宿主界面卡死。
- 修正每周热力图的高度标签处理，周柱继续表示连续的整周汇总高度。
- 修复 Linux 宿主字节码来源和数据库路径定位，并释放 SQLite 驱动资源，降低 Windows 卸载时的文件占用。

## 构建与兼容性

基于 SPW 1.19.2 构建。包结构检查已通过。宿主插件管理器在同一 SPW 进程内热替换已加载插件时可能失败；更新时建议完全退出 SPW 后再安装新包。真实窗口、AOT、DWM 材质和多插件共存仍需按当前环境核对。
