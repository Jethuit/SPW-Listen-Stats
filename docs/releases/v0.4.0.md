# v0.4.0

本次更新集中改进统计刷新、插件入口准备和长日期范围图表，并新增关于与可选更新提醒。

## 性能与稳定性

- 复用未变化的统计快照和排行索引，减少重复读取、合并与聚合；优化大量历史记录下新增播放记录的刷新路径。
- 宿主 Hook 目标首次完整发现并注册成功后保存描述缓存。后续启用及重启播放器后，宿主未变化时复用定位结果；宿主内容或插件版本变化时重新发现。
- 完善 Hook 安装失败的回滚和句柄清理：只有确认完整回滚后才重试；清理失败时停止重复注册，避免遗留 Hook 被误当作已释放。
- 优化长自定义日期范围的折线、曲线绘制，缓存完整点坐标、曲线、填充路径及当前像素分辨率的静态图层。悬停单独更新提示和高亮，保留全部数据点、原插值算法和日期选择精度。

## 关于与更新提醒

- 统计页右上角新增“ⓘ 关于”，可查看插件版本、上次检查时间和更新状态，并保留手动检查入口。
- 增加“为微软商店版启用更新提醒”开关，默认关闭，也可在插件配置中修改。
- 开启后，距上次检查尝试至少 24 小时才自动检查 GitHub 正式版；自动失败不打扰，手动失败明确提示。
- 发现更高正式版时，“关于”按钮显示蓝点，每个版本最多自动轻提示一次。点击“查看发布页”后自行下载安装，不自动替换插件。
- 更新检查只读取公开版本信息，不发送听歌记录，不识别或处理创意工坊渠道。

## 界面修正

- 修复关于及日期范围弹窗的背景遮罩随鼠标悬停变深、产生闪烁的问题。
- 精简关于弹窗布局；右上角按钮顺序调整为“…”、“ⓘ”。
- 明细卡片关闭图标与日期标题垂直居中对齐。

## 升级与兼容

- 安装包：`SPW-Stats-v0.4.0.spmod`，通过 SPW 模组管理本地导入。
- 沿用现有插件数据目录、统计口径和备份格式。首次启用新版本需要重新定位宿主，完整接入后再生成当前版本的 Hook 缓存。
- 可选更新检查会访问 GitHub；提醒开关关闭时仍可手动检查。
- 宿主界面接入仍受 SPW 结构与权限影响。离线结构检查覆盖本机 SPW 1.19.3 及保留的 1.19.0，不代表所有环境、材质或多插件组合均已实机验收。

## 验证说明

- 开发阶段已完成统计回归、Hook 缓存失效／回滚／启停竞态回归，以及图表缓存失效、日期命中、明细交互和图像对照。
- 三档合成日期范围的离屏对照确认长范围悬停整体耗时下降；离屏测量不作为 SPW 实机帧率或所有设备的性能承诺。
- 正式包另行检查版本、结构及与最终开发源码的一致性。正式产物的安装、启用、打开和返回仍需发布前实机确认。
