# v0.4.0

## 性能提升

- **统计刷新更快**：数据没有变化时，不再重复计算统计和排行；听歌记录较多时，新增记录后的刷新速度也得到改善。
- **再次启用更快**：首次启用会查找播放器中的页面和入口，后续启用及重启播放器后可复用结果，减少等待。播放器内容或插件版本变化时会重新查找。
- **长范围图表悬停更流畅**：查看跨月、跨年的折线或曲线图时，移动鼠标更流畅，保留全部每日数据、原有曲线形状和日期选择精度。

## 新增更新提醒

- 统计页右上角新增“ⓘ 关于”按钮，可查看插件版本、上次成功检查时间和更新状态，也可手动检查更新。
- 增加“为微软商店版启用更新提醒”开关，默认关闭。开启后自动检查 GitHub 正式版本，至少间隔 24 小时；自动检查失败不打扰，手动检查失败会提示原因。
- 发现新正式版本时，“关于”按钮显示蓝点，每个新版本最多自动提醒一次。
- 点击“查看发布页”后自行下载安装，不会自动下载或安装更新。
- 检查更新不发送听歌记录。Steam 创意工坊的更新仍由 Steam 处理。

## 界面修复

- 修复打开“关于”或日期范围弹窗后，移动鼠标导致背景变暗、闪烁的问题。
- 精简“关于”窗口布局，调整部分按钮的排列和对齐。
- 改善插件启用失败时的处理，避免重复入口。

## 安装说明

- 手动安装包：`SPW-Stats-v0.4.0.spmod`，在 SPW 的“模组管理”中本地导入。
- 继续使用原有数据目录，听歌时长、播放次数的计算规则和备份格式不变。
