# v0.5.0

## 新增

- 歌曲排行新增“下一首播放”按钮，鼠标悬停歌曲行时显示；播放次数榜与收听时长榜均可使用。连续添加按点击顺序插入，不再弹出添加成功的绿色通知。
- 新增统计入口位置开关，可在顶部图标和左侧栏目间切换；左侧栏目名称为“统计”，切换栏目时保持正确的选中状态。
- 统计页右上角新增齿轮按钮，可直接打开本插件的配置界面。

## 调整

- 设置按“常规、显示、动画、更新与诊断”分组，保留原有配置。
- 关于弹窗的作者信息移至项目链接右侧，同排显示。
- 更新开关统一命名为“自动检查更新”，说明补充“Steam创意工坊渠道无需开启”。

## 修复

- 修复导入或停用插件时，同步等待界面线程可能导致超时并提示必须重启的问题。

## 安装与兼容性

- 手动安装包：`SPW-Stats-v0.5.0.spmod`，在 SPW 的“模组管理”中本地导入；保留原有统计数据、计算规则和备份格式。
- 如果当前已加载的旧版在导入时提示必须重启，请完全退出并重新启动 SPW，使新版生效。
- 基于 SPW 1.19.3 构建。侧栏、配置跳转和队列操作依赖宿主内部接口；空队列时添加歌曲可能由宿主开始播放。
- 已完成源码编译、静态和合成回归及包结构检查；实际音频、队列和导入行为仍需实机确认，不能据此保证其他宿主版本的兼容性。
