# v0.5.1

## 性能优化

- 插件启用时优先加载统计入口，减少统计历史预读对启动的资源争用。
- 优化首次统计数据准备，减少重复文件检查、会话合并和临时对象分配；保留原有统计规则、去重方式和源文件删除检查。
- 概览入场完成后在后台预计算排行榜，兼顾首次打开和后续切页。

## 封面显示

- 专辑封面改为直角正方形，移除外框和底色，仅显示封面图片；排行与歌曲明细共用此样式。
- 大尺寸封面采用逐级缩小与 Mitchell 三次插值，改善细纹理缩小时的颗粒、锯齿和摩尔纹；保留透明通道，并按显示 DPI 生成缩略图。

## 诊断改进

- 增加入口接入、界面排队、权限复核、各组 Hook 安装及首次数据准备的分段耗时日志，便于定位启动和打开速度问题。

## 安装与兼容性

- 手动安装包：`SPW-Stats-v0.5.1.spmod`，在 SPW 的“模组管理”中本地导入；沿用原有统计数据、配置和备份格式。
- 基于 SPW 1.19.3 构建，保留原有权限。宿主内部接入仍可能受播放器升级影响。
- 本轮开发已通过相关数据、缓存、导航、封面合成回归与包结构检查；实际启动耗时与封面观感以本机宿主环境为准，合成检查不代表其他宿主版本已验收。
