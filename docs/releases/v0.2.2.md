## 更新日志

v0.2.2 正式版 · 2026/10/23

### 页面切换与插件共存

1. 整页切换采用与 SPW 桌面一致的弹簧参数：进入时从下方滑入；明确返回时向下滑出并淡出，原页面同时淡入。
2. 直接切换到其他页面时，新页面在统计页上方进入并覆盖，统计页原位淡出；不再先播放返回动画，也不等待旧页面退出后才显示目标。
3. 修复“专辑 → 听歌统计 → 歌曲或其他页面”时短暂恢复专辑页面的问题。
4. 调整统计页与宿主内容层的隔离，修复快速切换统计与歌词等插件时的页面叠加；保留其他插件的离开确认，避免重复导航关闭刚打开的工具页。
5. 快速反向切换沿用当前动画状态，不排队播放；转场期间收起弹层并屏蔽统计控件，避免误触和过期回调造成额外跳转。内部概览、排行及翻页仍保留各自的切换动画。

### 排行、图表与菜单

1. 排行类型菜单顺序调整为“标题／艺术家／专辑”。歌曲模式上方仍显示“歌曲播放次数”，表格前两列为“排名／标题”；艺术家模式统一使用“艺术家”称呼。
2. 单日按小时的折线、平滑曲线及填充延伸至绘图区左右边界，补齐首尾半个区间；数据点和时间标签仍居中对应各小时区间。
3. 顶部蓝色导航横线的宽度与“图标＋间隔＋文字”一致，不再包含按钮左右内边距。
4. 右上角导入、导出菜单使用与其他下拉菜单一致的主题背景、圆角和细描边。

适用于 **SPW 1.19.0 / 1.19.1**。下载 `SPW-Stats-v0.2.2.spmod`，在 SPW 模组管理中本地导入并启用。本次保留原有统计数据和备份格式，无需清空数据。

统计页仍通过宿主内容层接入，尚未成为原生 NavDisplay 场景，也不包含完整的原生页面生命周期或预测返回集成。兼容性依赖宿主内部接口，其他 SPW 版本不保证可用。

验证包括 Kotlin 构建、安装包结构、导航回归与离屏页面隔离检查；真实窗口材质、AOT 模式及不同歌词插件构建的共存效果仍需实机核对。

使用说明见 [README](https://github.com/Jethuit/SPW-Listen-Stats#readme)。
