# v0.4.1

## 新增

- 歌曲排行支持双击播放所选单曲，播放次数榜和收听时长榜均可使用；单击不播放。
- 概览与排行／歌曲明细可分别选择中文或 h/m/s 时长单位，默认使用中文。
- 返回关闭统计页后，可通过鼠标前进侧键恢复统计页。

## 界面优化

- 排行和歌曲明细的小时、分钟、秒按列对齐，统一中文与 h/m/s 单位的间距。
- 歌曲明细省略零分钟，底部合计时长与列表对齐。
- 关于弹窗增加作者、项目主页、问题反馈和开源许可入口，调整文字按钮宽度。

## 安装与兼容性

- 手动安装包：`SPW-Stats-v0.4.1.spmod`，在 SPW 的“模组管理”中本地导入。
- 基于 SPW 1.19.3 构建，保留原有统计数据、计算规则和备份格式。
- 双击播放和前进恢复依赖宿主内部接口，当前按 SPW 1.19.3 核对；实际音频、队列与鼠标侧键行为仍需实机确认，静态和合成检查不代表跨版本兼容性已经验收。
