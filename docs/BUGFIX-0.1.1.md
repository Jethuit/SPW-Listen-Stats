# v0.1.1：统计页与宿主导航联动

日期：2026-10-19。用户实机反馈：打开统计页后，点击侧栏“歌曲”“曲风”等栏目不能看到目标页面，鼠标侧键也不能退出统计页。

## 原因与修复

统计页通过 `AppNavigation.afterComposable` 叠加在宿主内容区，由插件自己的可见状态控制，没有接入宿主导航。宿主切页或返回时，覆盖其上的统计页仍然显示。

新增针对 SPW 1.19.0 `Navigator` 的普通方法钩子：

- `navigate(ScreenRoute)`、`replace(ScreenRoute)`、`forward()`：先关闭统计页，再保留宿主原导航操作。即使宿主选择当前页面后直接返回，也会关闭统计页。
- `back()`：统计页可见时只关闭统计页，并跳过本次宿主返回，避免一次操作同时退出两层；不可见时完整保留宿主返回行为。
- 停用清理全部钩子；注册中途失败会回滚已注册项目，UI 钩子注册失败时也清理导航钩子。

本机 1.19.0 二进制确认 `Navigator` 的上述方法签名；主窗口导航事件的返回回调指向 `Navigator.back()`。不新增全局鼠标监听，不修改宿主返回栈，不增加权限。继续依赖宿主内部导航类，其他 SPW 版本不能据此认定兼容。
